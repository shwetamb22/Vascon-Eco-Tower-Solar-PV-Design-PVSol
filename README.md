# Rooftop Solar PV Design for Vascon Eco Tower Using PV\*SOL

## Project Overview

This project presents the design and simulation of a **grid-connected rooftop solar PV system** for a commercial building using **PV\*SOL**. Vascon Eco Tower, Pune, was used as the site reference to develop the rooftop model and PV system design.

The project includes **3D rooftop modelling, PV layout and shading analysis, module and inverter selection, string and MPPT configuration, electrical system design, single-line diagram (SLD), and PV performance simulation**.

## Key Outcomes

- Designed a **251-module commercial rooftop PV system** using PV\*SOL.
- Created the building rooftop and PV array using the **3D modelling environment**.
- Performed **module placement and shading analysis**.
- Configured PV modules, inverter, strings, and **MPPT connections**.
- Developed the electrical configuration and generated the **system SLD**.
- Analysed PV generation, irradiation, system performance, and building energy consumption.
